# iPhone — بلا حساب Apple مدفوع

آخر تحديث: 16 أوت 2026 · commit `1e0184b`

## الخلاصة

**Push حقيقي يعمل على iPhone مجاناً، عبر Expo Go.**

خدمة Expo Push تُسلّم باستخدام **شهادات Apple الخاصة بـExpo**، لا شهادتك.
لذلك يصل الإشعار من Apple نفسها إلى هاتفك — والتطبيق في الخلفية أو **مغلق
تماماً** — بلا شهادة ولا اشتراك ولا Mac.

لم أستخدم أي حيلة ولا شهادة غير رسمية. Expo Go تطبيق رسمي من App Store.

---

## لماذا لا polling

فحصت الخيار ورفضته: **polling لا يعمل والتطبيق مغلق**، وهذه بالضبط اللحظة
التي تحتاج فيها سماع الطلب. كان سيستهلك بطاريتك ليقدّم أقل. iOS يوقف تنفيذ
JavaScript تماماً عند إغلاق التطبيق، و`background-fetch` يستيقظ حسب مزاج
النظام — قد يمر ساعات.

Push الحقيقي أفضل في كل بُعد، وهو متاح مجاناً. لذلك لم أضف polling إطلاقاً.

---

## ما الذي جعل هذا ممكناً

`react-native-mmkv` كانت **معلَنة في package.json ولا تُستورد في أي سطر**،
وكانت الاعتمادية الوحيدة التي تمنع المشروع من العمل داخل Expo Go. التخزين
الفعلي `expo-secure-store` في كل مكان. حذفها لم يكلّف شيئاً وفتح الطريق كلّه.

فحصت الاعتماديات الـ34 كلها: **جميعها متوافقة مع Expo Go**.

## التشغيل على iPhone

### 1 · ثبّت Expo Go

من App Store: <https://apps.apple.com/app/expo-go/id982107779> — مجاني.

### 2 · شغّل الخادم من حاسوبك

```bash
cd apps/mobile && npx expo start
```

### 3 · افتح التطبيق

امسح الـQR الظاهر في الطرفية بكاميرا iPhone (نفس شبكة الواي-فاي).

خارج الشبكة المحلية:

```bash
cd apps/mobile && npx expo start --tunnel
```

### 4 · اقبل الإذن

سجّل الدخول ← اقبل إذن الإشعارات عند ظهوره. يُسجَّل الجهاز تلقائياً.

---

## اختبار الإشعار

1. **الإعدادات ← الإشعارات ← «اختبار من الخادم»**
2. **أغلق التطبيق تماماً** (اسحبه من مبدّل التطبيقات)
3. يجب أن يصل الإشعار مع صوت
4. اضغطه ← يفتح الطلب مباشرة

ثم اطلب طلباً حقيقياً من متجرك — يصل خلال ثوانٍ.

## القيود — بصراحة

**الصوت المخصص غير ممكن.** صوت الصندوق ملف داخل حزمة تطبيقنا، وفي Expo Go
الحزمة حزمتهم لا حزمتنا. iPhone يرنّ بصوت النظام الافتراضي. **Android يحتفظ
بصوت الصندوق كاملاً.**

**الإشعار يحمل هوية Expo Go** لا أيقونة COMMERCO.

**قيود iOS التي لا يتجاوزها أحد** — لا Shopify ولا غيره:
- الوضع الصامت: يصل بلا صوت
- التركيز/عدم الإزعاج: مُعلَّم `time-sensitive` فيخترق **إن سمحت** بذلك، وليس مضموناً

**يحتاج `expo start` يعمل** على حاسوبك لتحميل الكود أول مرة. بعد التحميل
يبقى الإشعار يصل حتى لو أغلقت الحاسوب، لأن التسليم من Apple لا من حاسوبك.

## إن أردت لاحقاً النسخة الكاملة

كل إعدادات iOS الأصلية محفوظة في المشروع ولم أحذفها: `bundleIdentifier`،
الاستحقاقات، `aps-environment` المربوط بملف البناء، ومُرسِل APNs على الخادم.

إن اشتركت يوماً في Apple Developer، الأمر التالي يبني نسخة كاملة بأيقونتك
وصوت الصندوق — بلا أي كود إضافي:

```bash
cd apps/mobile && npx eas-cli build --platform ios --profile preview
```

عندها تحتاج `APNS_KEY_P8` و`APNS_KEY_ID` و`APNS_TEAM_ID`
و`APNS_BUNDLE_ID=store.commerco.merchant` في Vercel. الخادم يوجّه حسب شكل
الرمز، فالمسارات الثلاثة تتعايش بلا تعارض.

## إن فشل شيء

| العرض | السبب |
|---|---|
| لا يصل شيء | تحقّق من الإذن: الإعدادات ← الإشعارات ← بطاقة التشخيص |
| `DeviceNotRegistered` | أُغلق Expo Go أو أُلغي التسجيل — أعد فتح التطبيق |
| يصل بلا صوت | الوضع الصامت، أو `sound_enabled` مغلق لهذا الجهاز |
| لا يفتح الطلب | تأكّد أن الإشعار من طلب حقيقي لا من اختبار محلي |

للتحقق من سلامة الإعداد قبل أي شيء:

```bash
cd apps/mobile && npm run test:ios-config
```
